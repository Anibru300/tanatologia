# Tanatólogo

Sitio web profesional para servicios de tanatología.

## Estructura del proyecto

```
PROYECTO TANATOLOGO/
├── assets/
│   ├── css/          # Hojas de estilo
│   ├── js/           # Scripts de JavaScript
│   ├── images/       # Imágenes del sitio
│   └── fonts/        # Tipografías personalizadas
├── components/       # Fragmentos HTML reutilizables
├── pages/            # Páginas adicionales
├── docs/             # Documentación y recursos del cliente
├── index.html        # Página principal
└── README.md         # Este archivo
```

## Instrucciones de uso

1. Abre `index.html` en tu navegador para ver el sitio.
2. Guarda las imágenes en `assets/images/`.
3. Edita los estilos en `assets/css/main.css`.
4. Agrega interactividad en `assets/js/main.js`.
