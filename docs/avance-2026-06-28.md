## Estructura del repositorio

- `platform/web/` — Código fuente de la plataforma React (Vite + React + TypeScript + Tailwind).
- `platform/supabase/migrations/` — Esquema inicial de base de datos.
- `app/` — Build de producción publicado en GitHub Pages.
- `index.html`, `assets/`, `pages/` — Sitio estático original.
- `docs/` — Documentación del proyecto.
- `AGENTS.md` — Instrucciones para agentes de desarrollo.

## Mejoras de diseño y UX implementadas hoy

### 1. Sistema de diseño
- Nuevo componente `Stepper` para flujos paso a paso.
- Tarjetas más informativas con estados visuales.
- Formularios, botones y badges consistentes.

### 2. Flujo de agendar cita (paciente)
Wizard de 4 pasos:
1. Selección de servicio.
2. Selección de terapeuta.
3. Fecha y hora.
4. Confirmación con resumen y pantalla de éxito.

### 3. Directorio de terapeutas
- Búsqueda por nombre/especialidad.
- Filtro por especialidad.
- Tarjetas con calificación, verificación y precio.
- Modal de perfil completo.

### 4. Dashboards con datos de ejemplo
- **Paciente**: próxima sesión, avance de programa, acciones rápidas, estado de cuenta.
- **Profesional**: citas del día, pacientes activos, ingresos, calificación, verificación.
- **Administración**: métricas, alertas, verificaciones pendientes, gráfica de crecimiento, reportes.

### 5. Landing unificada
- El sitio original conserva su diseño y contenido.
- Los enlaces de "Iniciar sesión" apuntan a `/app/login`.
- `pages/login.html` redirige automáticamente a la plataforma.
- El logo dentro de la plataforma regresa al sitio principal.

### 6. Onboarding y registro
- Selector visual de rol (Paciente / Profesional / Administración).
- Pantalla de éxito al registrarse.
