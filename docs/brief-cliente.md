# Brief del Cliente — SOMOS-CALMA

## Idea de negocio
**Marca:** SOMOS-CALMA  
**Tagline:** *Tu espacio seguro para sanar y encontrar alivio.*  
**País de operación:** México

Crear una plataforma especializada en salud mental (psicólogos y tanatólogos) con un modelo de membresía y formación. La plataforma debe:

- Formar tanatólogos que pertenezcan a la comunidad.
- Ofrecer formación continua.
- Generar citas/consultas para los profesionales.
- Permitir contratación mensual o anual a manera de membresía.

## Modelo de ingresos sugerido (MVP)

### Membresía del Profesional (B2B)
El psicólogo/tanatólogo paga una suscripción mensual o anual y recibe:

- Acceso ilimitado a formación (cursos, talleres, actualizaciones).
- Perfil en el directorio para recibir pacientes.
- Software para gestionar citas y expedientes.

### Membresía del Paciente (B2C)
El usuario final paga una suscripción mensual:

- **Plan Acompañamiento:** 2 sesiones al mes + recursos de apoyo (meditaciones, lecturas de duelo).
- **Plan Proceso:** 4 sesiones al mes (terapia semanal).

### Reparto de ingresos
La plataforma cobra la membresía al paciente, retiene una comisión por infraestructura (~20%) y paga al terapeuta el resto por sesión atendida.

## Arquitectura tecnológica recomendada para el MVP (No-Code / Low-Code)

| Función | Herramienta sugerida |
|---|---|
| Página web y directorio | WordPress + Elementor / Framer |
| Área de formación (LMS) | Kajabi, Podia o LearnDash en WordPress |
| Reservas y calendario | Calendly o Acuity Scheduling |
| Consultas virtuales | Daily.co, Whereby o Zoom Healthcare |
| Pagos recurrentes | Stripe o PayPal Subscriptions |
| Matching del paciente | Typeform / Tally + filtros de directorio |
| Automatizaciones | Zapier o Make |

## Reclutamiento de profesionales fundadores
- Buscar 10–15 psicólogos/tanatólogos iniciales.
- Ofrecer entrada gratis los primeros 3 meses o tarifa preferencial de por vida.
- Subir el primer curso de formación (aliarse con un tanatólogo senior).

## Matching del paciente (cuestionario inicial)
1. ¿Qué motivo te trae aquí? (duelo por fallecimiento, ruptura, ansiedad, etc.)
2. ¿Prefieres terapia individual o de pareja?
3. ¿Qué horarios tienes disponibles?
4. ¿Modalidad preferida? (videollamada, llamada, chat)

Resultado: mostrar los 3 perfiles de terapeutas que mejor se adapten.

## Cumplimiento legal y privacidad
- Aviso de privacidad estricto (protección de datos del país).
- Términos y condiciones con deslinde de emergencias psiquiátricas.
- Redirección a líneas de emergencia ante crisis severas o riesgo suicida.

## Lanzamiento propuesto (3 meses)

### Mes 1 — Estructura
- Montar web base y pasarelas de pago.
- Configurar membresías y automatizaciones.

### Mes 2 — Contenido y reclutamiento
- Grabar el primer curso.
- Atraer a los primeros 15 terapeutas fundadores.

### Mes 3 — Tráfico y ventas
- Lanzar campañas digitales para captar pacientes.
- Iterar según métricas.
